## 四、开发原则

1. **每个版本发布前**：在对应 Issue 下留评论说明修复/实现情况
2. **不主动关闭 Issue**：等用户确认修复后再关闭
3. **保持向后兼容**：数据库 migration 不破坏已有数据
4. **CI 必须通过**：多平台构建全绿才能打 tag 发布
5. **CHANGELOG 同步更新**：每个版本都更新 CHANGELOG.md
