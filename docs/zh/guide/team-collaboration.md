# 团队协作

TrustRAG 支持个人空间和团队空间两种工作环境，方便组织共享知识库、对话和审核流程。

## 工作区类型

| 类型 | 说明 |
|------|------|
| **个人空间** | 私有工作区，每个用户默认创建。 |
| **团队空间** | 共享工作区，支持多成员协作和角色权限控制。 |

## 创建团队

1. 在侧边栏打开 **工作区** 视图
2. 点击 **创建团队**
3. 输入团队名称和可选描述
4. 系统自动生成邀请码

## 加入团队

1. 在侧边栏打开 **工作区** 视图
2. 点击 **加入团队**
3. 输入团队管理员提供的邀请码
4. 默认以 **查看者** 身份加入

## 角色权限

| 角色 | 权限 |
|------|------|
| **所有者** | 完全控制 — 管理成员、设置、API 配置、转让所有权、解散团队 |
| **管理员** | 管理成员、LLM 配置和 API Key |
| **编辑者** | 编辑文档和对话 |
| **查看者** | 查看文档和对话，提交审核 |

## 切换工作区

侧边栏顶部有工作区切换器，点击可在个人空间和团队空间之间切换。切换工作区时：

- 对话列表重新加载为当前工作区内容
- 文档和知识库同步更新
- 审核记录按当前工作区过滤

## 团队管理

团队所有者可在设置页面的 **团队设置** 面板进行管理：

- **邀请码** — 复制、重新生成或分享邀请码
- **成员管理** — 查看和管理成员，修改角色
- **转让所有权** — 将所有者角色转交给其他成员
- **解散团队** — 永久删除团队工作区（需二次确认）

## 数据隔离

每个工作区独立维护：
- 对话和聊天记录
- 上传的文档和知识库
- 审核记录和审计日志
- 模型配置（团队管理员控制共享的 LLM 设置）
