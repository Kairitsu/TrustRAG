# 知识图谱

TrustRAG 从您的文档中提取实体和关系，构建知识图谱。图谱可视化帮助您探索知识库中的关联。

## 访问知识图谱

1. 从侧边栏选择一个工作区
2. 导航到主导航中的**图谱**标签
3. 图谱会自动加载选定工作区的数据

## 关系图视图

交互式图谱可视化显示：

- **节点** — 从文档中提取的实体，按类型着色
- **边** — 实体之间的关系，带有标签和权重

### 实体类型颜色

| 类型 | 颜色 |
|------|------|
| 人物 (Person) | 蓝色 |
| 组织 (Organization) | 紫色 |
| 地点 (Location) | 绿色 |
| 概念/主题 (Concept) | 橙色 |
| 事件 (Event) | 红色 |
| 文档 (Document) | 青色 |
| 技术 (Technology) | 靛蓝色 |

### 交互操作

- **平移和缩放** — 使用滚轮或捏合缩放，拖动平移
- **点击节点** — 选择节点查看详情和关联实体
- **图例** — 显示当前图谱中的实体类型颜色

### 节点信息卡

点击节点显示：
- 实体名称和类型
- 来源文档 ID
- 关联实体和关系标签

## 实体列表

切换到**实体列表**标签浏览所有实体：

- **搜索** — 按名称或类型过滤实体
- **按类型分组** — 实体按类型组织，带颜色标识
- **数量统计** — 显示实体总数和类型数量

## API 接口

- `GET /workspaces/{ws_id}/knowledge-graph` — 返回图谱数据（节点 + 边）
- `GET /workspaces/{ws_id}/knowledge-graph/entities` — 返回实体列表和元数据
