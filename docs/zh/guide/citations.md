# 引用与审核

引用系统是 TrustRAG 区别于普通 RAG 工具的核心特性。

## 引用系统

### 内联引用链接

AI 回答正文中的引用标记（如 `[1]`、`[9]`）会自动渲染为**可点击的内联链接**。点击引用编号即可直接打开右侧引用详情面板，查看原文内容和审核控件。

无效的引用编号（引用不存在的来源）会自动检测并显示为普通文本，避免出现无效链接。

### 折叠引用来源

每段 AI 回答下方有一个可折叠的 **"引用来源"** 区域，以紧凑的标签形式列出所有引用。该区域**默认折叠**以节省屏幕空间。展开可浏览所有引用概览，或直接点击正文中的内联引用链接。

### 引用详情

点击引用标记可以查看：
- 来源文档名称
- 具体页码和段落位置
- 原文内容摘录
- 相关度评分

### 引用跳转

点击"查看原文"可直接跳转到文档的对应位置，方便上下文验证。

## 审核工作流

TrustRAG 提供内置的文档审核功能，支持对 AI 回答的逐段校对。

### 审核状态

| 状态 | 说明 |
|------|------|
| Approved | 已确认准确 |
| Rejected | 标记为不准确 |
| Flagged | 存疑，需要进一步核查 |
| Pending | 待审核（默认） |

### 审核流程

1. 查看 AI 回答
2. 逐条检查引用来源
3. 对每段引用标记审核状态
4. 不准确的引用可以添加批注和修正文本

## 审核报告

从审核记录页面可以导出综合审核报告，包含：

- **概览**: 总引用数、已审核/未审核数量、审核覆盖率
- **关键指标**: 通过率、拒绝率、幻觉率
- **审核明细**: 每条审核记录的文档上下文、引用文本、备注和修正

报告以 Markdown 格式生成，可一键复制用于分享或文档记录。

详见 [审核报告](/zh/guide/review-reports) 了解更多。

## 为什么需要引用？

- **可信度** — 用户可以验证 AI 回答是否有依据
- **透明度** — 清楚知道答案来源于哪些文档
- **可追溯** — 出现问题时可以追溯到原始材料
- **合规性** — 满足对信息来源可追溯的合规要求
