# 审核报告

TrustRAG 提供全面的审核报告生成功能，帮助您跟踪引用质量并识别潜在的 AI 幻觉。

## 生成报告

1. 从侧边栏导航到**审核记录**页面
2. 点击顶部工具栏中的**导出报告**按钮（摘要图标）
3. 弹出可视化报告对话框

## 报告内容

### 概览部分

| 指标 | 说明 |
|------|------|
| 总引用数 | 所有对话中的引用总数 |
| 已审核 | 至少有一条审核记录的引用 |
| 未审核 | 尚未审核的引用 |
| 审核覆盖率 | 已审核引用占总引用的百分比 |

### 关键指标

- **通过率** — 已审核引用中标记为通过的百分比
- **拒绝率** — 标记为拒绝的百分比
- **幻觉率** — 拒绝 + 存疑占已审核引用的百分比（指示潜在的 AI 幻觉）

### 审核明细

每条已审核的引用显示：
- 状态（通过/拒绝/存疑/待定）
- 来源文档标题
- 章节/标题路径
- 页码
- 引用文本
- 审核备注
- 修正内容（如有）

## Markdown 导出

点击报告对话框中的**复制 Markdown**，将完整报告以 Markdown 格式复制到剪贴板。

## API 接口

报告也可通过 REST API 获取：

- `GET /reviews/report` — JSON 格式报告数据
- `GET /reviews/report/markdown` — 预格式化的 Markdown 字符串
