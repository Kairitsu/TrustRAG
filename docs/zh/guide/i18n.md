# 多语言 (i18n)

TrustRAG 通过 Flutter 内置的国际化系统支持多种语言。

## 支持的语言

| 语言 | 代码 | 覆盖率 |
|------|------|--------|
| 简体中文 | `zh` | 100% |
| English | `en` | 100% |
| 日本語 | `ja` | 100% |
| 한국어 | `ko` | 100% |

## 切换语言

1. 从侧边栏进入**设置**
2. 找到**语言**部分
3. 选择您偏好的语言
4. UI 立即更新

语言偏好通过 SharedPreferences 保存，重启应用后保留。

## 开发者指南

### 添加新语言

1. 创建新的 ARB 文件：`apps/client/lib/l10n/app_xx.arb`（将 `xx` 替换为语言代码）
2. 从 `app_en.arb` 复制所有键，翻译对应的值
3. 在应用配置中添加对应的 locale
4. 运行 `flutter gen-l10n` 生成本地化委托

### 在代码中使用翻译

```dart
import '../../../l10n/app_localizations.dart';

// 在 Widget 中：
final s = S.of(context);
Text(s.navChat);              // 简单字符串
Text(s.loadFailed(error));    // 带参数的字符串
```
